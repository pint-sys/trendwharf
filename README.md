# Trendwharf

Trends in games, music, videos, news and memes, summarized in our own words with links to the original sources.

Live site: https://pint-sys.github.io/trendwharf/

## Files
- `index.html` – page structure and navigation
- `styles.css` – colors, layout, dark mode
- `app.js` – routing, filters, search, static pages
- `config.js` – site name, contact email, form link, analytics (edit this one)
- `data/items.json` – published trend items (replace with your Google Sheet export)

## Run locally
    python3 -m http.server 8000
